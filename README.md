# JP Excursões — demonstração

Protótipos estáticos e responsivos em português.

- `cliente/`: destinos do litoral do Sudeste, busca por destino, excursões e galerias.
- `administrador/`: cadastro completo e edição de excursões, passageiros, pagamentos, lançamentos financeiros e pendências.

Demonstração pública sem autenticação ou backend. Todos os registros são fictícios. Alterações ficam na sessão e não são sincronizadas entre os sites.
