# Bora — viagens e painel

Protótipos estáticos e responsivos em português.

- `cliente/`: viagens, galerias, reservas e avaliações.
- `administrador/`: viagens, reservas, pagamentos e pendências.

Demonstração pública sem autenticação ou backend. Todos os registros são fictícios. Alterações ficam na sessão e não são sincronizadas entre os sites.
